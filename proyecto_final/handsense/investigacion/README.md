## Criterio para futuras investigaciones

Cada análisis nuevo debe registrar fecha, pregunta, fuentes con enlaces directos, hallazgos comprobados, inferencias, límites y decisión de diseño. La ausencia de un producto encontrado no demuestra que una idea sea inédita o patentable.
